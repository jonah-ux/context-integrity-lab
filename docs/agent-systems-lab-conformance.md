# Agent Systems Lab context conformance

Context Integrity Lab remains the owner of `context-integrity/v1`. This fixture
and test make its admission/refusal boundary explicit without importing Agent
Proof at runtime.

The owner proves supported, wrong-scope, stale, fresh-but-irrelevant, and
unavailable-source dispositions with explicit `ok`, `observed`, `partial`,
`timed_out`, citations, and unknowns. The native result may contain answer text;
the manifest therefore records that a downstream adapter allowlist is required.
Agent Proof owns that `agent-proof/interop/v1` handoff and decides which fields
may cross the evidence boundary.

Run the focused conformance test from a fresh checkout. Fixtures are fictional
and contain no personal, customer, transcript, or provider data.
