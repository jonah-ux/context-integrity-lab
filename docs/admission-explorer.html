04 / limits

Useful guardrails, bounded claims

no magic

The page mirrors the decision vocabulary; it does not call the Python implementation. The CLI and tests remain the executable proof.

  • supported means selected records match scope, freshness, and question terms.
  • stale keeps old records visible but refuses to present them as current.
  • unavailable covers an out-of-scope person/project and carries no citation.
  • It does not prove model accuracy, production scale, or external adoption.
