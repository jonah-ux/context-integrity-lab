# Security policy

Context Integrity Lab is a local, synthetic demonstration. It does not make
network calls, authenticate users, read employer systems, or store credentials.

## Reporting a concern

Please do not post sensitive details in a public issue. Use GitHub's private
vulnerability reporting channel for this repository when it is available. If
that channel is unavailable, open a minimal public issue requesting a private
contact path without including the suspected secret or exploit details.

Include a concise impact statement, the affected version or commit, and a safe
reproduction that uses fictional data. Remove tokens, personal information,
private URLs, and customer or employer records before sharing any artifact.

## Scope

Reports about the deterministic admission logic, unsafe fixture handling, or
unexpected file/network behavior are in scope. Model accuracy, production
availability, and third-party integrations are outside this repository's
claims because the project has no model or external service dependency.
